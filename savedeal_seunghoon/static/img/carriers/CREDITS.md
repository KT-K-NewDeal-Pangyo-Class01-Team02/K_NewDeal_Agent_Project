# 통신사 로고 출처

번호이동 예약의 "기존 통신사 → KT" 표시에 쓰는 로고입니다. 위키미디어 공용의 SVG를 위키미디어가 PNG로 렌더링한 파일(가로 240px)을 받았습니다.

| 파일 | 원본 | 이미지 라이선스 |
|---|---|---|
| `kt.png` | [KT Logo.svg](https://commons.wikimedia.org/wiki/File:KT_Logo.svg) | Public domain |
| `skt.png` | [SK Telecom Logo.svg](https://commons.wikimedia.org/wiki/File:SK_Telecom_Logo.svg) | Public domain |
| `lguplus.png` | [LG U+ CI.svg](https://commons.wikimedia.org/wiki/File:LG_U%2B_CI.svg) | Public domain |

- 이미지 저작권은 퍼블릭 도메인이지만 **로고는 각 회사의 등록상표**입니다. 이 프로젝트에서는 고객의 기존 통신사를 식별하는 용도로만 씁니다.
- `kt.png`는 위키미디어에 올라 있는 KT 로고(빨간 곡선이 있는 소문자 kt)입니다. 현재 사용 중인 공식 CI와 다르면 교체해 주세요.
